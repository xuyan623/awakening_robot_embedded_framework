# async

`async` 是 AWLF 的异步执行基础库，用于承接跨模块复用的异步机制能力。

## 目标定位

1. 提供通用异步执行机制（执行器、工作队列、延时任务、任务生命周期管理）。
2. 不承载业务语义，不直接实现通信策略（如 Topic 路由、QoS 策略）。
3. 作为 `services/comm` 等上层模块的可复用基础设施。

## 依赖边界

1. 允许依赖：`lib/core`、`lib/osal`、`lib/sync`。
2. 不允许依赖：`lib/drivers`、`lib/services/comm` 等上层业务模块。
3. 时间语义统一通过 `lib/osal` 提供的单调时间接口获取。

## 阶段约束

1. 当前阶段仅完成模块落位与边界冻结。
2. 具体 API、类型与实现细节在实现阶段再冻结。
